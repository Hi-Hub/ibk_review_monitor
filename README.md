# IBK i-ONE Bank 5개 앱 - 부정 리뷰 모니터링 프로그램

매일 실행하면 아래 **5개 앱 x 2개 스토어 = 10개 채널**에서 **부정적인 리뷰만**
모아서 **최신순**으로 정리한 엑셀 파일을 만들어줍니다. 맨 앞 탭에는
**앱별·날짜별 신규 건수**를 한눈에 볼 수 있는 요약표가 포함됩니다.

## 📌 핵심 기능

1. **5개 앱 전체**를 한 번에 수집 (App Store + Google Play)
2. **부정적인 리뷰만** 저장합니다 (기본: 별점 2점 이하). 긍정/중립 리뷰는 제외됩니다.
3. 모든 리뷰는 **최신순(날짜 내림차순)** 으로 정렬되어 표시됩니다.
4. 엑셀에는 4개 항목이 정리됩니다: `일시` / `사용자ID` / `리뷰` / `불만사항`
5. **총 11개의 탭**으로 구성됩니다.
   - 맨 앞 **[일자별건수요약]** 탭: 날짜 x 앱(채널)별로 "그 날짜에 작성된 부정
     리뷰 건수"를 한 장의 표로 정리. 신규 여부와 무관하게 이번 실행에서 수집된
     모든 부정 리뷰를 작성일자 기준으로 집계합니다. 가로축은 10개 채널, 세로축은
     날짜, 맨 오른쪽과 맨 아래에는 합계가 표시됩니다.
   - 이어서 10개의 채널별 탭: `안드로이드개인 · IOS개인 · 안드로이드기업 · IOS기업 · 안드로이드알림 · IOS알림 · 안드로이드미니 · IOS미니 · 안드로이드글로벌 · IOS글로벌`
     각 탭 맨 위에는 탭 이름이 큰 제목으로 표시됩니다.
6. 한 채널에서 오류가 발생해도 나머지 채널은 멈추지 않고 계속 진행되며,
   이미 정상 처리된 채널의 기록은 절대 사라지지 않습니다.

> 참고: 별도의 색상 강조(노란색 표시) 기능은 포함되어 있지 않습니다. 대신
> [일자별건수요약] 탭과 각 채널 탭 상단의 "그 중 신규 N건" 문구로 신규 여부를
> 확인할 수 있습니다.

## ⚠️ "불만사항" 분류에 대한 중요한 참고사항

불만사항 분류는 **AI가 의미를 이해해서 분류하는 것이 아니라, 리뷰 내용에
특정 키워드가 포함되어 있는지로 분류하는 방식**입니다.

- 예: "로그인이 안 돼요" → '로그인' 키워드 포함 → **로그인**으로 분류
- 키워드와 무관한 표현으로 불만을 적은 경우 **기타**로 분류될 수 있습니다.

분류 정확도를 높이고 싶다면 `config.json`의 `complaint_categories` 항목에서
키워드를 자유롭게 추가/수정할 수 있습니다 (메모장으로 열어서 편집 가능).

## 📂 폴더 구성

```
ibk_review_monitor/
├─ review_monitor.py       ← 실제 동작하는 프로그램(코드) — 이제 엑셀 + 폰앱용 데이터도 같이 만듭니다
├─ config.json             ← 설정 파일(앱 정보, 부정 기준, 불만 키워드 등)
├─ requirements.txt        ← 필요한 패키지 목록
├─ setup.bat               ← [최초 1회] 더블클릭하면 설치 진행 (PC에서 직접 쓸 때만 필요)
├─ run_report.bat          ← [매번] 더블클릭하면 리포트 생성 (PC에서 직접 쓸 때만 필요)
├─ docs/                   ← 📱 폰 앱(홈 화면 아이콘) 화면 파일들 — 이 폴더를 인터넷에 올릴 겁니다
│  ├─ index.html           ← 앱 화면
│  ├─ manifest.json        ← "홈 화면에 추가"할 때 앱 이름/아이콘 정보
│  ├─ service-worker.js    ← 앱이 빨리 켜지게 해주는 파일
│  ├─ icons/               ← 앱 아이콘 이미지
│  └─ data.json            ← 매일 자동으로 갱신되는 리뷰 데이터 (자동 생성)
├─ .github/workflows/daily.yml  ← 매일 아침 자동으로 리뷰를 수집해주는 설정 (GitHub이 대신 실행)
├─ reports/                ← 결과 엑셀 파일이 여기에 쌓입니다 (자동 생성)
├─ data/                   ← 중복 방지 기록 + 전체 누적 CSV (자동 생성)
└─ logs/                   ← 실행 기록 (오류 발생 시 확인용, 자동 생성)
```

## 📱 폰에서 앱처럼 쓰기 (GitHub 무료 방식)

이 방법을 쓰면 **회사 컴퓨터를 켜두지 않아도**, 매일 아침 자동으로 리뷰가
수집되고, 폰에서 아이콘을 눌러 앱처럼 결과를 볼 수 있습니다.

> ⚠️ **먼저 꼭 알아야 할 것**: 아래 방법은 무료로 하는 대신, 이 저장소를
> **공개(Public)** 로 만들어야 합니다. 즉 이 안의 리뷰 데이터(리뷰 내용, 작성자
> 표시 등)와 코드를 **인터넷의 누구나 볼 수 있게** 됩니다. 회사 정책상 문제가
>없는지 반드시 먼저 확인하세요.

### 1) GitHub 계정 만들기
1. https://github.com 접속 → 우측 상단 **[Sign up]** → 이메일/비밀번호로 무료 가입

### 2) 저장소(repository) 만들기
1. 로그인 후 우측 상단 **[+]** 버튼 → **[New repository]**
2. Repository name에 원하는 이름 입력 (예: `ibk-review-monitor`)
3. **Public** 선택 (Private 아님 — Pages 무료 기능을 쓰려면 Public이어야 합니다)
4. **[Create repository]** 클릭

### 3) 이 폴더의 파일을 통째로 업로드하기
1. **GitHub Desktop**이라는 무료 프로그램을 설치하세요: https://desktop.github.com
   (명령어를 몰라도 마우스 클릭만으로 업로드할 수 있게 해주는 프로그램입니다)
2. GitHub Desktop 실행 → 아까 만든 GitHub 계정으로 로그인
3. **[File] → [Add local repository]** → 이 `ibk_review_monitor` 폴더 선택
   ("이 폴더는 아직 저장소가 아닙니다"라는 메시지가 뜨면 **[create a repository]** 클릭)
4. 화면 하단에 파일 목록이 보이면, 왼쪽 아래 **커밋 메시지**(예: "최초 업로드")를
   입력하고 **[Commit to main]** 클릭
5. 오른쪽 위 **[Publish repository]** 클릭 → "Keep this code private" 체크를
   **해제**(꺼짐) 상태로 두고 → **[Publish repository]**
   (2번에서 이미 저장소를 만들었다면, Publish 대신 **[Push origin]** 버튼이 보일 수 있어요.
   그 경우 저장소 만들 때 이름을 다르게 했다면, 원격 저장소 주소를 아까 만든 것으로
   맞춰주세요.)

### 4) 자동 실행(GitHub Actions) 켜기
1. GitHub 웹사이트에서 방금 만든 저장소로 이동
2. 상단 메뉴 **[Actions]** 탭 클릭
3. "Workflows aren't being run on this forked repository" 같은 안내가 보이면
   **[I understand my workflows, go ahead and enable them]** 클릭
4. 왼쪽에 **"매일 부정 리뷰 수집"** 이라는 항목이 보이면 클릭 → 오른쪽
   **[Run workflow]** 버튼 클릭 (수동으로 한 번 먼저 실행해보는 것)
5. 1~2분 기다린 뒤 새로고침 → 초록색 체크(✅)가 뜨면 성공

### 5) 폰 앱 화면(GitHub Pages) 켜기
1. 저장소 상단 **[Settings]** 탭 클릭
2. 왼쪽 메뉴에서 **[Pages]** 클릭
3. "Build and deployment" → Source: **Deploy from a branch** 선택
4. Branch: **main**, 폴더: **/docs** 선택 → **[Save]**
5. 1~2분 뒤 페이지를 새로고침하면 `https://내아이디.github.io/ibk-review-monitor/`
   같은 주소가 나타납니다. 이게 앱 주소예요.

### 6) 폰 홈 화면에 아이콘으로 추가하기
**아이폰(Safari 브라우저로 열어야 함):**
1. 5)에서 만든 주소를 Safari로 열기
2. 하단 **공유 버튼**(사각형에 화살표) 탭
3. **[홈 화면에 추가]** 선택 → **[추가]**

**안드로이드(Chrome 브라우저):**
1. 주소를 Chrome으로 열기
2. 우측 상단 점 3개(⋮) 메뉴 → **[홈 화면에 추가]** 또는 **[앱 설치]**
3. 안내에 따라 추가

이제 폰 홈 화면에 "IBK 부정 리뷰 모니터링" 아이콘이 생기고, 눌러서 열면
주소창 없이 앱처럼 켜집니다. `.github/workflows/daily.yml` 설정 덕분에
매일 한국시간 오전 8시에 자동으로 리뷰를 수집해서 앱 화면 내용이 갱신됩니다.
(오래된 엑셀 파일과 로그는 저장소가 무한정 커지지 않도록 자동으로 정리됩니다.)

> 💡 **회사 PC에서 App Store/Google Play 접속이 막혀 있어서 예전에 문제였다면**,
> 이 방식은 그 문제도 자동으로 해결됩니다 — 리뷰 수집이 회사 네트워크가 아니라
> GitHub의 서버에서 실행되기 때문입니다.

> 💡 수동으로 지금 당장 한 번 더 갱신하고 싶다면, 언제든 4)의 **[Actions] → 매일
> 부정 리뷰 수집 → [Run workflow]** 를 눌러 즉시 실행할 수 있습니다.

## 💻 (선택) 예전처럼 회사 PC에서 엑셀만 뽑고 싶다면

위의 폰 앱 방식과 별개로, 아래 방법으로 지금까지처럼 컴퓨터에서 직접 실행해
엑셀 파일만 받아볼 수도 있습니다 (둘 다 동시에 사용해도 문제없습니다).



### 1단계. Python 설치 (컴퓨터에 처음 설치하는 경우만)

1. https://www.python.org/downloads/ 접속 → "Download Python 3.x.x" 클릭
2. 설치 시 **"Add python.exe to PATH" 체크박스를 꼭 체크**한 뒤 [Install Now] 클릭

이미 설치되어 있다면 건너뛰어도 됩니다.

---

### 2단계. 최초 1회 설치

`setup.bat` 파일을 **더블클릭**하세요. (인터넷 연결 필요, 1~2분 소요)

---

### 3단계. 실행하기

`run_report.bat` 파일을 **더블클릭**하세요.

- 완료되면 `reports` 폴더에 `부정리뷰리포트_20260630.xlsx` 같은 파일이 생성됩니다.
- 엑셀을 열면 맨 앞에 [일자별건수요약] 탭이 보이고, 이어서 채널별 탭 10개가 있습니다.
- 각 채널 탭은 최신 리뷰가 맨 위로 오도록 정렬되어 있습니다.
- 이 파일을 그대로 메일에 첨부하거나 공유하면 됩니다.

> ⚠️ **처음 실행할 때는** 최근 부정 리뷰가 모두 "신규"로 한꺼번에 표시됩니다.
> 두 번째 실행부터는 정말로 새로 올라온 것만 "신규"로 집계됩니다.

---

### 4단계. 매일 자동으로 실행되게 만들기 (Windows 작업 스케줄러)

1. 윈도우 검색창에 **"작업 스케줄러"** 입력 후 실행
2. 오른쪽 메뉴에서 **[기본 작업 만들기]** 클릭
3. 이름 입력 (예: `IBK 리뷰 모니터링`) → [다음]
4. 트리거에서 **[매일]** 선택 → [다음] → 시작 시간 설정 (예: 오전 8시) → [다음]
5. 동작에서 **[프로그램 시작]** 선택 → [다음]
6. "프로그램/스크립트"에서 **[찾아보기]** → `run_report.bat` 선택 → [다음] → [마침]

> 💡 컴퓨터가 꺼져 있으면 실행되지 않으니, 항상 켜져 있는 PC에 등록하는 것을 추천합니다.

## ⚙️ 설정 변경하기 (config.json)

메모장으로 `config.json`을 열면 아래 항목을 수정할 수 있습니다.

| 항목 | 설명 |
|---|---|
| `negative_max_rating` | 이 별점 이하를 "부정적 리뷰"로 분류 (기본값 2 = 1~2점만 부정) |
| `complaint_categories` | 불만사항 분류 키워드 목록 (자유롭게 추가/수정 가능) |
| `android_max_count` | Android 리뷰를 한 번에 몇 개까지 가져올지 |
| `apps` | 모니터링할 앱 목록 (앱 추가/제거 시 이 항목을 수정) |

## ❓ 문제 해결 (FAQ)

**Q. [일자별건수요약] 탭에 아무 숫자도 없어요.**
→ 정상입니다. 이번 실행에서 수집된 부정 리뷰가 없다는 뜻입니다.

**Q. 특정 탭에 "오류가 발생했습니다"라고 나와요.**
→ 해당 채널만 일시적으로 수집에 실패한 것이며, 나머지 탭에는 영향이 없습니다.
`logs/실행로그.txt`에서 자세한 오류 내용을 확인하세요. 보통 다음 실행 시
정상적으로 다시 수집됩니다.

**Q. 같은 리뷰가 매번 신규로 다시 잡혀요.**
→ 채널별로 즉시 저장하도록 구조가 되어 있어, 한 채널의 오류가 다른 채널의
기록에 영향을 주지 않습니다. 그래도 반복된다면 `data/state.json` 파일이
정상적으로 쓰기 가능한 위치에 있는지 확인해주세요.

**Q. 불만사항 분류가 이상하게 되어 있어요.**
→ 위의 "불만사항 분류에 대한 중요한 참고사항"을 참고하세요. 키워드 기반 분류라
완벽하지 않습니다. `config.json`에서 키워드를 보완하면 점점 정확해집니다.

**Q. 누적된 전체 기록은 어디서 보나요?**
→ `data/전체_부정리뷰_누적기록.csv` 파일에 매번 새로 확인된 부정 리뷰가 계속
추가되어 쌓입니다. 추이 분석에 활용하세요.
